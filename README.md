# Lumina Studio — Pure HTML5 & CSS3 Interactive Showcase

An interactive, multi-theme landing page and carousel showcase engineered with **100% HTML5 and CSS3**—no JavaScript required.

## Live Demo
View it live: `https://tanishkabonthula23-jpg.github.io/lumina-pure-css-showcase/`

## Advanced Pure-CSS Techniques Used
- **Zero-JS 4-Slide Carousel:** Powered by hidden `<input type="radio">` state controllers, `<label>` triggers, and CSS general sibling combinators (`~`).
- **Live 3-Palette Theme Switcher:** Switches global CSS Custom Properties (`--bg-main`, `--accent-1`, `--btn-gradient`) across Sunset, Coral, and Berry themes in real time.
- **3D Perspective Flip Cards:** Uses `perspective: 1000px`, `transform-style: preserve-3d`, and `backface-visibility: hidden`.
- **Glassmorphism & Ambient Keyframes:** Multi-layered `backdrop-filter: blur()` cards over floating radial orbs.

## Tech Stack
- **HTML5** (Semantic sections, `<details>`/`<summary>` native accordions)
- **CSS3** (Custom Properties, Grid, Flexbox, 3D Transforms, Keyframe Animations)
