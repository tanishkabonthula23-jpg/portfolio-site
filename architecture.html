Under The Hood

How the HTML & CSS work together

Explore the building blocks behind the automatic carousel, hover pause, and multi-page design.

How does the auto-moving carousel run without JavaScript?

The .carousel-track holds three side-by-side slides at 300% width and shifts via @keyframes autoSlideCycle using transform: translateX().

How does hovering pause the automatic slide movement?

Adding animation-play-state: paused on .auto-carousel:hover .carousel-track stops the slide transition smoothly while your cursor is over the showcase.

How are the 4 pages connected?

Each HTML file (index.html, solutions.html, architecture.html, and connect.html) links to the shared styles.css file and includes consistent top and footer navigation links.
