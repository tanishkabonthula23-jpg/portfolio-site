Philosophy & Process

How we approach digital craft

Good interfaces respect the reader's attention. We prioritize semantic markup, high contrast, and maintainable CSS tokens.

Step 01

Common Questions

Why use multiple HTML files instead of hiding everything on one page?

Separating pages into index.html, work.html, studio.html, and contact.html mirrors how real multi-page websites are structured and keeps each file clean and easy to read.

How can I customize the color palette later?

All core colors live inside :root custom properties at the top of styles.css, so you can update brand accents across all four pages from one place.
